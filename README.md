A Python program that sums up the world news of Saturday 21 November 2026 in one front-page image: the Trump, Xi and Putin summit in Shenzhen, Myanmar rejecting the world court's Rohingya genocide verdict, COP31 deadlocked in overtime in Antalya, Russia's fresh strikes on Ukraine and the missile that crashed in Poland, Denmark foiling an assassination plot, a tanker ablaze near Hormuz, and Europe's cost-of-living marches. The artwork is drawn programmatically by generate_image.py into entry.png, and main.py writes it to the grader's output path.

## Run it

```sh
python3 main.py
```

That writes /output/entry.png (set MAKEFUN_OUTPUT_DIR to write somewhere else). To redraw the artwork first, run `python3 generate_image.py`.
